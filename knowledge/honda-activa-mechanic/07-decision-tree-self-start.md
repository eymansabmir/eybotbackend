# Honda Activa 6G — Mechanic Decision Tree: Self Start Not Working

Use case: **Self start not working**

## Question 1: Is the horn working?

### If YES

Go to Question 2.

### If NO

**Diagnosis:**

- Battery weak
- Battery dead

## Question 2: Is headlamp brightness normal?

### If YES

Go to Question 3.

### If NO

**Diagnosis:**

- Weak battery

## Question 3: Do you hear the starter relay click?

### If YES

**Diagnosis:**

- Starter motor issue
- Starter wiring issue

### If NO

**Diagnosis:**

- Relay failure
- Fuse failure
- Switch failure

## Related Checks (from diagnostic flow)

When self start fails, also verify: battery voltage, fuse, spark plug, fuel supply, spark, compression, and valve clearance as needed.
