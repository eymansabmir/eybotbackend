## Simple RAG routing hints

- “mileage”, “office commute”, “petrol saving” -> commuter products
- “Splendor vs Xtreme” -> compare Splendor family with Xtreme 125R first unless the user specifies 160R/160R 4V
- “sporty”, “performance”, “fast” -> Xtreme 125R / Xtreme 160R / Xtreme 160R 4V
- “budget” -> HF 100 / HF Deluxe / Splendor+
- “features”, “Bluetooth”, “USB”, “digital meter” -> XTEC/XTEC 2.0/Glamour X
- “long ride”, “adventure”, “rough roads” -> Xpulse 210
