# Check RC / VAHAN Application Status

## User questions

- Check my RC status
- Track RC application
- Duplicate RC status
- RC transfer status
- Vehicle application status
- How do I track my VAHAN application?

## Answer

Check vehicle-related application status through VAHAN **Know Your Application Status**.

The VAHAN portal also provides transaction history, pending documents, receipt reprint, and uploaded document viewing where available.

## Portal

Vahan — https://vahan.parivahan.gov.in/vahanservice/vahan/

## What you may need

- Application reference or transaction details
- Vehicle registration number
