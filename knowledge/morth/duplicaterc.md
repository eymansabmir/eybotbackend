# Apply For Duplicate RC

## User Goal

Obtain duplicate registration certificate.

## Steps

1. Visit Vahan Citizen Services.
2. Enter Vehicle Registration Number.
3. Click Proceed.
4. Select Basic Services.
5. Enter last 5 digits of chassis number.
6. Validate vehicle.
7. Generate OTP.
8. Submit OTP.
9. Select Duplicate RC.
10. Fill service details.
11. Update insurance details.
12. Review fee details.
13. Submit application.
