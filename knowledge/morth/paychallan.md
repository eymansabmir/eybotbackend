# How To Pay A Traffic Challan

## User Goal

Pay a pending traffic challan online.

## Portal

https://echallan.parivahan.gov.in/challan/challan-services

## Steps

1. Open the eChallan portal.
2. Select "Check Pending Challan Status".
3. Search using:
   - Vehicle Number
   - Challan Number
   - Driving Licence Number
4. Review pending challans.
5. Select the challan to be paid.
6. Complete payment using available payment methods.
7. Download or print the payment receipt.

## Escalation

If payment succeeds but receipt is not generated:
- Check Pending Transaction.
- Download Payment Receipt.
- Raise Grievance through eChallan portal.
