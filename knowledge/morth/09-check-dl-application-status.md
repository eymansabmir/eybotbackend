# Check Driving Licence Application Status

## User questions

- Check my DL status
- Where is my driving licence?
- DL application status
- Track driving licence
- Has my driving licence been approved?
- Track my DL application

## Answer

Check driving licence application status through Sarathi Parivahan.

## Portal

Sarathi Parivahan — https://parivahan.gov.in

## What you may need

- Application or reference number
- Other details requested by the portal (DL number, date of birth, etc.)
